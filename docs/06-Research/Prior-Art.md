# Prior art

## Purpose

Prevent false novelty claims.

Fitifact combines established ideas into a potentially strong horizontal abstraction.

## Content adaptation

Transcoding/content adaptation has long existed to make content suitable for browser/device/channel capability. Do not claim invention.

## Grace — 2005

**Dynamic Web File Format Transformations with Grace**  
Daniel S. Swaney, Frank McCown, Michael L. Nelson.

Grace used an HTTP proxy to transform browser-incompatible/obsolete content into browser-viewable formats.

Relevant prior art:
- transparent compatibility adaptation;
- browser/destination-aware conversion.

Source:
- https://arxiv.org/abs/cs/0512068

## Claim policy

Safe:
> I wondered why file compatibility is still the user's problem, so I built an adapter.

Safe:
> Converters ask what format you want. This asks where the file needs to work.

Unsafe:
> I invented automatic file adaptation.

Unsafe without exhaustive research:
> World's first file adapter.
