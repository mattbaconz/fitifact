# Alternatives

Competition includes behaviors and workarounds.

## Manual conversion
Search “convert HEVC to H264,” then use FFmpeg/HandBrake/online tool.

Fitifact must remove diagnosis/settings work.

## Trial-and-error upload
Rename, compress, retry, change app, search error.

Fitifact saves retries.

## Ask ChatGPT/search
A model can explain an error. Fitifact must execute and validate safely, not merely advise.

## App-native adaptation
Android, ebook software, CMSs and media platforms can adapt internally.

Threat: horizontal layer less necessary if all destinations implement it.

Counter: most developers do not want to build/maintain their own pipelines.

## Share a cloud link
Often better when only attachment size is the problem. Fitifact should recommend it if adaptation would destroy quality.

## ZIP/archive
Sometimes helps transport, rarely solves actual media/document compatibility.

## Ask sender for another format
Legitimate alternative.

## Specialist tools
HandBrake, calibre, creative suites and CAD converters can beat a generic adapter on advanced semantics.

## Custom developer pipeline
`validate -> transform -> upload` is the biggest B2B alternative.

## No-op
Destination failure may be network/auth/server bug. If file appears compatible, Fitifact should say so instead of transforming blindly.
