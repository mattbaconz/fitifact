# Non-goals

Fitifact is not:
- a creative editor;
- a novelty anything-to-anything converter;
- a replacement for FFmpeg/ImageMagick;
- a media CDN;
- a file manager;
- a malware scanner;
- a DRM bypasser;
- an archival authenticity system;
- a platform scraper;
- “AI for file conversion”;
- a cloud-only gatekeeper;
- an automatic destructive optimizer;
- a promise of universal compatibility.

Some targets cannot faithfully represent source semantics. Refusal and uncertainty are legitimate results.
