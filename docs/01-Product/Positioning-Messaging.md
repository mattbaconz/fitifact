# Positioning and messaging

## Category
**File adapter** / **file compatibility layer**

Technical:
> Constraint-driven, minimum-mutation file adaptation.

## One-liners

Consumer:
> **Make any file fit where you need it.**

Developer:
> **Stop rejecting incompatible uploads. Adapt them.**

Technical:
> **Declare file constraints; Fitifact finds and executes the least-destructive valid transformation path.**

Infrastructure:
> **A compatibility layer between arbitrary files and arbitrary destinations.**

## Preferred tagline
> **Any file. Any destination. Make it work.**

Alternative:
> **Stop converting files. Make them compatible.**

## Avoid
- AI-powered file converter
- ultimate converter
- world's first automatic compatibility
- works everywhere
- zero quality loss when lossy work occurs
