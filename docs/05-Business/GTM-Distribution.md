# GTM and distribution

## Wedge

Start as a memorable FOSS utility, not an enterprise deck.

## Channels

### YouTube
Primary narrative:
> **I Made an Adapter for Files**

### GitHub
Trust, stars, contributors.

### Hacker News / Reddit / developer communities
Technical story:
destination-first, minimum mutation, local-first, open profile standard.

### Search
Intent terms:
- unsupported file upload;
- MP4 not accepted;
- make video compatible;
- file too large;
- fit under upload limit.

### Browser stores
Retention and discovery.

### Package registries
Developer adoption.

### Integrations
Uploaders, CMSs, automation platforms.

## Launch ladder

1. working core;
2. public repo;
3. web utility;
4. YouTube video;
5. technical write-up;
6. extension beta;
7. SDK/API preview.

## Consumer -> developer bridge

On successful web adaptation:
> Building an uploader? Make rejected files repair themselves.

## Community loop

Invite:
- destination profile PRs;
- incompatibility fixtures;
- providers;
- planner benchmarks.

## Avoid

- Product Hunt as the entire plan;
- AI converter ads;
- spam X-to-Y SEO;
- hundreds of unverified profiles;
- enterprise-first messaging.

## Viral mechanic

The best proof is:
`rejected -> diagnosis -> minimal changes -> accepted`.
