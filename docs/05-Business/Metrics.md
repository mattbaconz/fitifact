# Metrics

## North star

**Validated adaptations that solve a real incompatibility.**

Not raw conversion count.

## FOSS
- stars;
- contributors;
- profile PRs;
- CLI/SDK installs;
- dependents.

## Funnel

`visit -> file -> constraints -> mismatch -> plan -> execute -> validate -> accepted feedback`

## Rates

- no-op rate;
- plan availability;
- execution success;
- validation success;
- accepted-after-adaptation;
- repeat adaptation.

## Quality

- number of mutated properties;
- stream preservation rate;
- semantic-loss operations;
- validation failures by provider;
- size overshoot rate.

## Registry
- freshness;
- verified profiles;
- source coverage;
- failing profiles.

## SaaS
- active API developers;
- adaptation units;
- gross margin by family;
- cloud opt-in;
- enterprise expansion.

## Guardrails
- privacy complaints;
- unexpected cloud uploads: zero target;
- original overwrite incidents: zero target;
- false-compatible reports;
- security events.

## Resist vanity
- format count;
- raw files processed;
- total bytes without outcome.
