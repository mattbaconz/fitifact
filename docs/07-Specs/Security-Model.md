# Security model specification

## Trust boundaries

```text
user file          untrusted
user requirements  untrusted
page text          untrusted
community profile  untrusted data
verified profile   trusted data, never code
provider binary    privileged dependency
model output       untrusted
cloud worker       isolation boundary
```

## Rules

1. No user string becomes shell.
2. Profiles contain no code.
3. Provider args come from typed allowlisted values.
4. Transform network denied unless explicitly required.
5. Cloud workspace isolated per job.
6. File processing has resource ceilings.
7. Output paths generated by Fitifact.
8. Original immutable by default.
9. Cloud use explicit.
10. Models cannot authorize execution.

## v0.1 native enforcement

- `adapt` always inspects, checks, and plans from the requested input and typed
  constraints; JSON plans are informational and cannot be executed.
- System FFmpeg tools receive typed argv through `Command`, never a shell, with
  network media protocols denied and only `file` allowed.
- FFmpeg uses explicit no-clobber behavior. Originals and occupied outputs are
  never replaced, including persistence races.
- Changed output remains a hidden destination sibling until fresh constraint,
  integrity, expected-fact, and SHA-256 copied-stream validation passes.
- Probe/process output and time are bounded; external diagnostics shown to
  users are redacted stable messages.

## Example policy

```yaml
max_input_bytes: 2000000000
max_pixels: 100000000
max_duration_ms: 7200000
network: deny
allow_providers:
  - ffmpeg
  - image
```

## Native messaging

Native bridge accepts strict schema from authorized extension IDs only; no arbitrary command field.

## Security review triggers

Mandatory review for:
- archive extraction;
- office docs;
- SVG/HTML rendering;
- URL fetching;
- executable plugins;
- model-assisted parsing;
- external registries.
