Discord’s file size limit

Discord raised the free upload limit from 10 MB to 20 MB on 13 August 2026. Nitro Basic allows 50 MB, and Nitro up to 1 GB.

These numbers come from the same profiles Fitifact checks every result against. Fitifact can’t see your account, so pick the tier you have.

Why did my 18 MB clip fail?

  • Discord checks size before compressing Since August 2026 the mobile app checks the file you picked, not the smaller file it would send. Discord says Android users may hit the limit more often.
  • A converted clip can grow Users report that a phone’s HEVC clip gets converted to H.264 and ends up over the limit. Discord hasn’t documented this. Fitifact sends H.264 already, so there’s nothing left to convert.
  • 20 MB might mean 20,000,000 bytes Discord hasn’t said whether 20 MB is 20,000,000 bytes or 20 × 1024 × 1024. Fitifact aims at the smaller number.

How it works

  • Discord is already picked Choose your tier, then drop a clip.
  • Only what fails changes A clip that already fits keeps its original bytes.
  • The result is checked again Against the same rules, before you can download it.

What the browser can’t do

  • HDR video, and video stored rotated, mirrored, or stretched, go to the desktop app.
  • Files over 1 GiB are refused in the browser.
  • If this browser lacks an encoder the clip needs, Fitifact says so instead of guessing.
  • 20 MB is about 2.7 Mbit/s for a one-minute clip, so longer clips come out smaller or softer. Fitifact stops at a quality floor rather than send mush.
