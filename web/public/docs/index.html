Fitifact GitHub

Make your file work there

Drop a file, pick the place it has to work, and Fitifact inspects it. It changes only what that place rejects, then checks the result. If the file already works, Fitifact does nothing.

Your file stays on this device. Nothing is uploaded.

Photos in this browser

This page adapts still photos: JPEG, PNG, WebP, HEIC, TIFF, BMP, and GIF. Pick Discord, Gmail, GitHub, WhatsApp, Slack, X, or JPEG. Compatible photos download unchanged.

Video and audio

Video and sound use the desktop app. That app ships FFmpeg next to itself, so you do not install FFmpeg or edit PATH. GitHub Pages still adapts photos only. Fitifact does not run FFmpeg in the browser.

Download the unsigned Windows installer from GitHub Releases or the desktop-windows Actions artifact. Windows will warn. Checksums and source are the trust path for this release.

Sources: MP4, MOV, WebM, MKV, MP3, WAV, FLAC, M4A, OGG.

Full desktop notes live in apps/desktop/README.md. The command-line tool still expects ffmpeg and ffprobe on PATH.

Destinations

Discord, Gmail, WhatsApp, Slack, X, GitHub, and generic web image or video each have a documented ceiling. Fitifact cannot see Discord Nitro. Pick the cap your account actually has.

If the form said something else, paste the rejection. Fitifact uses the size, format, and dimension rules it understands, and tells you what it ignored.

What stays, what changes

After a destination is chosen, Fitifact shows what was wrong, what it will change, what it will keep, and whether the result is verified against those rules. The destination may still have extra undocumented rules.

What Fitifact will not do

PDF, ZIP, Office documents, and SVG are refused. GitHub Pages adapts photos only. Video and audio use the desktop app, which ships FFmpeg.
